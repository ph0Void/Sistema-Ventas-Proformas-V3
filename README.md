# Sistema-Ventas-Proformas-V3-
# 📊 Sistema de Ventas y Proformas

Proyecto completo (Backend + Frontend) para la **gestión integral de ventas y proformas** en una tienda virtual.  
Incluye administración de productos, clientes y vendedores, con autenticación segura, reportes interactivos y generación de documentos en PDF.  

---

## 🚀 Descripción General

El sistema está orientado a pequeñas y medianas empresas que buscan optimizar procesos comerciales:  
- Registro y control de ventas.  
- Generación de proformas (cotizaciones) con conversión directa a venta.  
- Gestión de clientes, productos y vendedores.  
- Visualización de reportes interactivos y exportación de facturas en PDF.  

El proyecto está dividido en dos partes:  

- **Backend (Java + Spring Boot + PostgreSQL)**  
- **Frontend (React + Next.js + Tailwind CSS)**  

---

## 🛠️ Tecnologías principales

### Backend
- **Java 21**
- **Spring Boot** (API REST, validaciones)
- **Spring Security + JWT** (autenticación y autorización)
- **PostgreSQL** (base de datos relacional)
- **Maven** (gestión de dependencias)
- **Cloudinary** (gestión de imágenes)
- **OpenAPI / Swagger** (documentación de la API REST)

### Frontend
- **React + Next.js** (framework frontend)
- **TypeScript**
- **Tailwind CSS** (diseño responsivo)
- **Zustand** (gestión de estado global)
- **Chart.js** (gráficos dinámicos)
- **jsPDF** (exportación de documentos a PDF)
- **Fetch API** (consumo de endpoints)
- **Git / GitHub** (control de versiones)

---

## 🔑 Características principales

### Backend
- Gestión de **productos y categorías** con CRUD completo y almacenamiento de imágenes en Cloudinary.
- Registro de **clientes y vendedores**.
- **Sistema de ventas:** registro de operaciones, cálculo de totales y control de stock.
- **Proformas (cotizaciones):** creación, edición y conversión en ventas.
- **Seguridad:** endpoints protegidos con JWT.
- API documentada con Swagger (`/swagger-ui.html`).

### Frontend
- Interfaz completa para **gestión de productos, clientes y ventas**.
- **Proformas dinámicas**, editables y convertibles a ventas.
- **Gráficos comparativos** de ventas y proformas.
- **Exportación en PDF** de facturas y proformas.
- **Sistema de autenticación y perfiles**.
- **Notificaciones interactivas** para alertas importantes.

---

## ⚙️ Flujo Principal

1. **Registro/Login** con JWT.  
2. **Gestión de productos y clientes** desde el panel administrativo.  
3. **Generación de proformas** seleccionando productos y cantidades para clientes.  
4. **Conversión de proformas en ventas reales** (actualización automática de stock).  
5. **Visualización de estadísticas** con tablas interactivas y gráficos.  
6. **Exportación automática a PDF** de facturas o proformas.
